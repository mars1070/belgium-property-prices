# Belgium property prices (Statbel, 2010-2026)

Median sale prices of houses and apartments in Belgium, by commune, province, region and nationwide, per year since 2010 and for the first half of 2026.

- Data: [`data.csv`](data.csv), 37,427 rows
- Website: https://mars1070.github.io/belgium-property-prices/

## Columns

`nis_code, level, region, name_fr, name_nl, name_en, property_type, year, period, median_price_eur, sales_count, q1_price_eur, q3_price_eur, source, license`

- `level`: national, region, province or commune
- `property_type`: HOUSE, HOUSE_CLOSED, HOUSE_DETACHED, APARTMENT
- `period`: `Y` for a full year, otherwise a half-year
